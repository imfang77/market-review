板块RPS 口径与其他说明

板块RPS 定义：把每个板块当作一只"股票"，按其 N 日收益率在 通达信401个板块内 做百分位排名（100 = 最强，≥ 90 为领先板块）。板块RPS5 / 板块RPS10 / 板块RPS20 以及 板块RPS60 / 板块RPS120 / 板块RPS240 / 板块RPS250 与个股RPS 是相互独立的两套体系，请勿混淆。

两线红 = 板块RPS5 / 板块RPS10 / 板块RPS20 中至少 2 条 ≥ 90（RPS 到了 90 才叫转红，表中 ≥ 90 标红）。两线转红日 = 该板块最近一次由"非两线红"跳变为"两线红"的交易日。领先周期数 = 板块RPS5/10/20 中 ≥ 90 的个数（0~3）。注意：板块RPS60 / 120 / 240 不参与两线红判定，仅用于表格展示与「板块RPS自定义」筛选条件。

涨跌幅列：涨跌幅5日% / 10日% / 20日% 为板块对应周期的收益率（百分比数值，表头已含 %，单元格内为纯数字）。

日期区间（已取消，由「N日内首次两线转红」替代）：两线红默认按最新交易日（页面顶部数据日期）查看"当前两线红板块"（数值列始终为最新交易日快照，仅"是否两线红 / 两线转红日"随口径变化）。勾选「N日内首次两线转红」即按"两线转红日落在近 N 个交易日"筛选，对应交易日区间实时显示在勾选框右侧（例如 N=5 即最近 5 个交易日）；不再提供独立的起止日期选择器。
