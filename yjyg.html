口径说明：业绩预告取自东方财富数据中心(RPT_PUBLIC_OP_NEWPREDICT)，筛选「业绩预告对应的报告期」为下个报告期——三季报(2026-09-30)与年报(2026-12-31)；范围限定为中报(2026-06-30)结束后至 2026-10-21发布公告者（即剔除中报预告）。下一交易日涨幅 = 公告日后首个交易日(前复权)收盘 / 公告日收盘 − 1；成交金额(亿) = 下一交易日成交额 / 1e8，取自腾讯自选股单日行情；至今涨幅 = 最新收盘(2026-10-20) / 公告日收盘 − 1。净利润 / 扣非净利润 / 营业收入增幅区间取自东方财富业绩预告各行内容的同比增幅（ADD_AMP，单位 %），按「归属于上市公司股东的净利润」「扣除非经常性损益后的净利润」「营业收入」三行分别提取其下限/上限；未披露该指标行的预告（如部分北交所公司的定性描述「净利润有下降风险」等）对应单元格标记「—」。概念/主题取自与通达信同步的 401 个板块(来源 _board_map_auto.json，由 tdx_board_map_auto.py 从本机通达信目录自动生成)，按个股所属板块展示（一只股票可归属多个板块，单元格内自动换行显示全量）。待开市：公告日 ≥ 2026-10-20，下一交易日(2026-10-21 周三)尚未开市，公告日收盘亦未取得，故下一交易日 / 下一交易日涨幅 / 成交额 / 至今涨幅均暂缺（标记为「待开市 / —」）；上市前发布预告的个股（公告日早于上市首日、或公告日当天即为上市首日）无公告日真实收盘，同样标记「—」。顶部「预告类型」提供全部预告类型快速筛选（按数量降序：预增 / 略增 / 预减 / 扭亏 / 减亏 / 首亏 / 略减）；「公告日期」下拉可直接选择公告日（选项含当日条数、按日期倒序、随其它筛选实时更新）；「个股」支持关键字模糊筛选（代码/名称）；点表头可升/降序；表头 ▾ 可按该列关键字筛选；概念/主题下拉数量随其它筛选实时更新。
